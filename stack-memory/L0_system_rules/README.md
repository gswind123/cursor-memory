# L0_system_rules（硬规则）

## 本层放什么

- 格式与解析契约（如 HEADER、指令行语法边界）。
- 与加载/执行强相关的不可违背约束（以权威文档与广泛一致的存量为准）。

## 本层不要放什么

- 具体案例的长正文产物（对白、整段脚本、长示例）。
- 风格偏好类内容（放 L1）。
- **归档技能默认不写本层**：避免把「会话结论」误升格为硬规则。

## 归档写入例外

仅当用户**明确要求**新增 L0 条目，且能提供可引用证据/契约时，才可新建 `L0_system_rules/<rule>.md`；否则把候选结论写在 L1（如「待升格为 L0」）。

## 新增 L0 的门槛

仅在确有硬规则缺失且证据明确时增补；不确定时不要写入 L0。
