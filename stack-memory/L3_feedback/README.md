# L3_feedback（踩坑与反例）

## 本层放什么

- 低效写法、易错组合、与 L0/L1 冲突的实践。
- **现象 → 原因 → 建议修正**（可引用 L0/L1/L2 路径或小节名）。

## 本层不要放什么

- 把反例当作风格来源；避错不能推翻硬规则与 L1 方法论。
- 无修正建议的纯吐槽。
- **不可推翻 L0/L1**。

## 归档写入时注意

- 优先写入既有分类（如 [`work_assistant/`](work_assistant/README.md)）；新建分类时同步 [`INDEX.md`](../INDEX.md) 与分类 `README.md`。
