# L1_project_knowledge（项目知识 · 主写入层）

## 本层放什么

- 可脱离具体案例复用的策略：节奏、结构、术语分工、指令参数语义、组合模式等。
- **工作助手主写入文件**（可直接由归档技能更新）：
  - [`work_goals.md`](work_goals.md) — 当前阶段目标（可变，建议定期滚动）。
  - [`decisions_and_constraints.md`](decisions_and_constraints.md) — 决策与约束。
  - [`project_context.md`](project_context.md) — 业务与领域上下文。

## 本层不要放什么

- 完整正文产物、流水账式会话记录。
- 绑定具体人物/隐私事件的记录。
- 无法泛化的偶然写法（可降到 L2 一句反例或口头说明）。

## 归档写入时注意

- 条目保持短小、可验证；长对话压缩为结论要点。
- 组合模式类文件建议在顶部维护 **`## 模式目录`** 作为单一事实来源。
