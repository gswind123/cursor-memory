# L2_examples（Few-shot · 极简示例）

## 本层放什么

- 按子目录分类的**极简片段**（通常每个案例 **1～3 行/段**）。
- 建议结构：`##` 区分用途说明、片段、可选「一句不要怎么做」。

## 本层不要放什么

- 长篇正文、大量连续脚本。
- 与分类无关的杂项（应新建 `/<category>/` 或归入既有分类）。
- **不可推翻 L0/L1**。

## 写入时注意

- 仅当模式**可泛化**时再写入；新建 `/<category>/` 时同步 [`INDEX.md`](../INDEX.md) 与本层或分类 `README.md`。
